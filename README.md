# Автоинструктор

Навигатор с голосом инструктора для начинающего водителя. Работает на iPhone как обычное приложение и не требует интернета, когда карта скачана.

## Как поставить на iPhone (один раз, ~10 минут)

Приложению нужен адрес в интернете с `https://`. Без него iPhone не даст геопозицию и не позволит работать офлайн. Самый простой бесплатный вариант — GitHub Pages:

1. Зарегистрируйся на https://github.com (бесплатно).
2. Нажми **+ → New repository**, назови его, например, `instructor`, выбери **Public** и нажми **Create repository**.
3. На странице репозитория нажми **uploading an existing file**. Перетащи туда **все файлы и папки** из архива (`index.html`, `app.js`, `core.js`, `style.css`, `sw.js`, `manifest.webmanifest`, папки `icons` и `vendor`) и нажми **Commit changes**.
4. Открой **Settings → Pages**. В разделе **Branch** выбери `main`, папку `/ (root)` и нажми **Save**.
5. Через 1–2 минуты появится адрес вида `https://ТВОЙ-НИК.github.io/instructor/`.
6. На iPhone открой этот адрес **в Safari** и нажми **Поделиться → На экран «Домой»**.
7. Запусти приложение с экрана «Домой» и нажми **Карта города → Скачать Таганрог**. Скачивание займёт 1–3 минуты, лучше делать по Wi‑Fi.
8. Когда спросит доступ к геопозиции, нажми **Разрешить**.

После этого карта, поиск, маршруты и голосовые подсказки работают без интернета.

## Что умеет

- Офлайн-карта Таганрога и поиск адреса («Петровская 50»), без интернета.
- Построение маршрута прямо в телефоне и автоматическое перестроение, если свернула не туда.
- **Спокойный маршрут** — по возможности по небольшим улицам, а не по магистралям.
- Голос инструктора:
  - про каждый манёвр говорит три раза: заранее, при подготовке (зеркало, поворотник, ряд) и в момент поворота;
  - предупреждает о светофорах, пешеходных переходах, знаках «Стоп» и «Уступи дорогу», лежачих полицейских и ж/д переездах;
  - говорит о превышении скорости и мягко отмечает резкие торможения;
  - на спокойных участках даёт советы и хвалит.
- **Просто покататься** — режим без маршрута, в котором приложение следит только за скоростью.
- **Чек-лист перед поездкой**, который можно прослушать голосом.
- **Мои поездки** — разбор каждой поездки и прогресс.
- **Демо** — приложение само «проезжает» маршрут, чтобы послушать подсказки дома.

## Важно

- Это помощник, а не замена инструктору. Пока она учится, рядом должен сидеть опытный водитель.
- Данные о знаках и ограничениях скорости берутся из OpenStreetMap и бывают неполными. **Знаки на дороге всегда главнее приложения.**
- Во время поездки экран должен быть включён, а приложение — открыто. Если свернуть приложение, iOS остановит навигацию.
- Для красивого русского голоса: Настройки iPhone → Универсальный доступ → Устный контент → Голоса → Русский → «Милена (улучшенный)».

## Как устроено (для разработчика)

- `core.js` — ядро без зависимостей: граф дорог из OpenStreetMap (Overpass API), поиск пути A*, манёвры (включая кольца с номером съезда), голосовые фразы, сессия поездки (привязка к маршруту, уход с маршрута, скорость, торможения).
- `app.js` — интерфейс: карта Leaflet, хранение офлайн-данных в IndexedDB, речь через Web Speech API, режим демо, история и настройки.
- `sw.js` — service worker: кэширует приложение и просмотренные плитки карты. Без интернета карта рисуется из скачанных данных о дорогах.
